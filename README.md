# 「のぞけるディスプレイ」のチュートリアル

**のぞけるディスプレイ**は、2026年度第78回東北大学学園祭における、東北大学メタバース研究会の展示です。以下はチュートリアルです。


## 事前準備
- opentrackをインストール
https://github.com/opentrack/opentrack/releases から、opentrack-2026.1.0-win32-setup.exe
をダウンロード。


- ARマーカーの入手

https://github.com/opentrack/opentrack/blob/unstable/contrib/aruco/test3.png をダウンロードして印刷する。サイズは5cm程度なら何でもいい。


- config.iniの設定

このファイル(README.md)と同じフォルダのconfig.iniを開き、
screen_diagonal_inches（ディスプレイのインチ）、
screen_aspect_width（アスペクト比の横の長さ）、
screen_aspect_height（アスペクト比の縦の長さ）
をディスプレイに合わせて変更。

例えば、16インチのPCなら、
screen_diagonal_inches=16
screen_aspect_width=16
screen_aspect_height=10
にする。

## 使い方

1.このアプリを起動

2.opentrackが自動で起動し、数秒後にトラッキングも自動で開始される（開始されない場合は、opentrackの画面の「start」をクリック）

3.ARマーカーをカメラにかざす

4.ホーム画面でモードを選ぶ（どのモードからも Esc でホーム画面に戻る）

- **本番モード**: 覗き込みカメラを全画面で表示する。展示中はこのモードにする
- **検査モード**: 左に俯瞰カメラ、右に覗き込みカメラを並べて表示する。頭の動きと見え方を同時に確認できる
- **編集モード**: オブジェクトの配置と、覗き込みカメラの設定を行う

俯瞰カメラは、右ドラッグで回転、ホイールでズーム、ホイールを押しながらのドラッグで平行移動できる。

## 編集モード

画面の上のメニューと、右のパネルで操作する。変更は「ファイル → 保存」(Ctrl+S) を押すまでファイルに書き込まれない。

### シーン

シーンは、ワールド（Blender などで作った .glb）、のぞき窓の位置、ワールドへの変更、アプリで追加したオブジェクトをまとめたもの。アプリ内に何個でも保存しておける。

- 「ファイル → 開く」で、保存してあるシーンに切り替える。最後に開いたシーンが、次に起動したときと本番モードで使われる
- 「ファイル → 新規シーン」で空のシーンを作り、「名前を付けて保存」で名前を付ける
- 保存先は scenes フォルダ（このファイルと同じ場所）の `<名前>.ini`。画面サイズと目の距離はシーンではなく config.ini に保存される
- 以前の scene.ini は、初めて起動したときに scenes/default.ini に移される

### Blender でワールドを作る

1. Blender でワールドを作る。長さの単位はメートル
2. ディスプレイ面の中心にカメラを置き、名前を `peek_window` にして、画面の奥（見せたい方向）に向ける。覗き込みカメラの基準になる
3. ライトは入れてもよい（入っていれば、アプリのライトは消える）
4. 「ファイル → エクスポート → glTF 2.0」で .glb として書き出す（「+Y が上」は初期設定のまま）
5. アプリの「ファイル → インポート → ワールド (.glb)…」で取り込む。assets/worlds/ にコピーされ、同じ名前のシーンが作られる。のぞき窓は `peek_window` の位置と向きに合わせられる

Blender で直して同じファイルに書き出し直したときは、「ファイル → ワールドを再読み込み」で表示を更新できる。

### オブジェクトを直す

- ワールドの中のオブジェクト（Blender で親を持たないもの）も、一覧か俯瞰画面での左クリックで選んで、位置・回転・大きさを変えたり、非表示にしたりできる。変更は Blender のオブジェクト名で覚えるので、Blender で書き出し直しても残る
  - 変更したオブジェクトは、Blender でそのオブジェクトを動かしても反映されない。「Blender の値に戻す」で変更を消すと、Blender での位置に戻る
  - Blender でオブジェクトの名前を変えると、そのオブジェクトへの変更は効かなくなる
  - 大きさは、Blender での大きさに掛ける倍率
- 「ファイル → インポート → モデル (.glb / .gltf)…」で、ワールドとは別にモデルを足せる。assets/models/imported/ にコピーされ、大きさは自動で約30cmに合わせる。複製・削除もできる。FBX は事前に Blender などで glb に変換しておく
- のぞき窓（ディスプレイ）は、位置・向き、画面サイズ、目と画面の距離を変えられる。「Blender の位置に戻す」で `peek_window` の位置に戻る

### 共有

「ファイル → エクスポート → シーン (.zip)…」で、今のシーンとワールド・モデルのファイルを1つの .zip にまとめる。受け取った側は「ファイル → インポート → シーン (.zip)…」で、同じシーンを再現できる（zip の名前でシーンとして保存される）。

### キー操作

選択中のオブジェクト（またはのぞき窓）は、キーでも動かせる（パネルで文字を入力している間は効かない）。すべての操作方法は「ヘルプ → 操作方法」にもある。

| キー | 操作 |
|---|---|
| ↑ / ↓ | Z軸に沿って移動（↑で -Z） |
| ← / → | X軸に沿って移動（→で +X） |
| PageUp / PageDown | 上下に移動 |
| R / F | X軸まわりに回転 |
| Q / E | Y軸まわりに回転 |
| Z / X | Z軸まわりに回転 |
| + / - | 拡大・縮小 |
| Shift を押しながら | ゆっくり動かす |
| Ctrl+Z / Ctrl+Shift+Z | 元に戻す / やり直し（Ctrl+Y でもやり直し） |
| Ctrl+S / Ctrl+Shift+S | 保存 / 名前を付けて保存 |
| Ctrl+N | 新規シーン |
