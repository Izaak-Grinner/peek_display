# 「のぞけるディスプレイ」のチュートリアル

**のぞけるディスプレイ**は、2026年度第78回東北大学学園祭における、東北大学メタバース研究会の展示です。以下はチュートリアルです。


## 事前準備
- opentrackをインストール
https://github.com/opentrack/opentrack/releases から、opentrack-2026.1.0-win32-setup.exe
をダウンロード。


- ARマーカーの入手

https://github.com/opentrack/opentrack/blob/unstable/contrib/aruco/test3.png をダウンロードして印刷する。黒い四角の一辺が **4cm** になるように印刷するのがいちばん正確（OpenTrack はマーカーを 4cm として距離を計算する）。4cm 以外で印刷したときは、定規で測った一辺の長さを、編集モードの「スクリーン → 機材（このPC）→ トラッキング → マーカーの大きさ」に入れる（アプリが頭の動きをその比で直す）。


- 機材プロファイル（config.ini）の設定

このファイル(README.md)と同じフォルダの config.ini は、このPCと設置場所の値（機材プロファイル）。シーンには入らない。編集モードの「スクリーン → 機材（このPC）」からも変えられる。画面の比率は、モニターの画素数から自動で求めるので入力しない。

| 項目 | 内容 |
|---|---|
| screen_diagonal_inches | 画面（映る部分、縁は含めない）の対角のインチ |
| screen_width_mm | 定規で測った、映る部分の幅（mm）。0 より大きければ対角の代わりに使う（測った値のほうが正確） |
| viewer_base_distance / viewer_min_distance | センター合わせのときの目と画面の距離 / これ以上近づけない距離（メートル） |
| opentrack_path | OpenTrack の実行ファイルの場所 |
| minimize_opentrack | OpenTrack をタスクトレイで起動するか |
| camera_fov_deg | カメラの対角の視野角（度、初期値 56） |
| marker_size_cm | 印刷したマーカーの一辺（cm、初期値 4） |

アプリは起動のたびに、OpenTrack のプロファイル（ドキュメント\opentrack-2.3\display.ini）に、アプリの前提の値（aruco トラッカー、UDP 出力、センター合わせ C、開始 F12、動きの範囲）と、上の視野角を書き込み、OpenTrack が使うプロファイルをこの display に切り替えてから起動する（OpenTrack の画面でほかのプロファイルを選んでいても、次の起動で display に戻る）。視野角を編集モードで変えて保存すると、OpenTrack を起動し直す。使うカメラは OpenTrack の画面で選ぶ。

## 使い方

1.このアプリを起動

2.opentrackが自動で起動し、数秒後にトラッキングも自動で開始される（開始されない場合は、opentrackの画面の「start」をクリック）

3.ARマーカーをカメラにかざす

4.ホーム画面の「シーン」で表示するシーンを選び、モードを選ぶ（どのモードからも Esc でホーム画面に戻る）。選んだシーンは、次に起動したときと編集モードでも開く

- **本番モード**: メインカメラ（頭の動きに合わせて動く、画面に映すカメラ）を全画面で表示する（ウィンドウも全画面になる）。展示中はこのモードにする
- **検査モード**: 左にシーンビュー（シーン全体を外から見る画面）、右にメインカメラを並べて表示する。頭の動きと見え方を同時に確認できる
- **編集モード**: オブジェクトとスクリーンの配置を行う

シーンビューは、右ドラッグで回転、ホイールでズーム、ホイールを押しながらのドラッグで平行移動できる。編集モードでは、シーンビューの右下にメインカメラの映像（カメラプレビュー）が出る（「表示 → カメラプレビュー」で消せる）。

## 編集モード

画面の上のメニューと、右のパネルで操作する。変更は「ファイル → 保存」(Ctrl+S) を押すまでファイルに書き込まれない。

### シーン

シーンは、スクリーン（仮想空間に置いた、実際のディスプレイ）の位置、ライト、オブジェクト（モデル（.glb / .gltf）など）をまとめたもの。モデルのファイルの中身も含めて、`.peek` という1つのファイルになる。アプリ内に何個でも保存しておける。

- 「ファイル → 開く」（またはホーム画面の「シーン」）で、保存してあるシーンに切り替える。最後に開いたシーンが、次に起動したときと本番モードで使われる
- 「ファイル → 新規シーン」で新しいシーンを作り、「名前を付けて保存」で名前を付ける。新しいシーンには、チェッカー模様の床と壁の「部屋」のモデルが最初から置いてある
- 「ファイル → シーンを削除」で、保存してあるシーンを削除する（中のモデルも一緒に消える）。開いているシーンを削除したときは、ほかのシーンが開く
- 保存先は scenes フォルダ（このファイルと同じ場所）の `<名前>.peek`。中身は zip で、設定（scene.ini）とモデルのファイルが入っている
- 画面サイズ・目の距離・トラッキングの値は、シーンではなく機材プロファイル（config.ini）に保存される
- シーンには、作ったときの画面の大きさ（基準の画面）が記録される（初めて保存したときの画面。スクリーンのプロパティの「今の画面を基準にする」で変えられる）。大きさの違う画面で開いたときは、基準の画面に映っていた範囲が全部入るように、シーンを見る縮尺を自動で変える（比率が違う分は、上下か左右が少し余分に見える）。縮尺が変わっていると、スクリーンのプロパティに表示され、シーンビューに基準の画面が灰色の枠で出る

### ワールドを入れる

Blender で作ったワールド（部屋・家具・背景など）は、「ファイル → インポート → ワールド (.glb / .gltf)…」で取り込む。

1. Blender でワールドを作る。長さの単位はメートル
2. （任意）ディスプレイ面の中心にカメラを置き、名前を `peekScreen` にして（大文字・小文字も同じに）、画面の奥（見せたい方向）に向ける。入っていれば、スクリーンがその位置と向きに合わせられる。入れなければ、取り込んだあとアプリでスクリーンを置く
3. ライトは入れてもよい（入っていれば、アプリの太陽光は消える）
4. 「ファイル → エクスポート → glTF 2.0」で .glb として書き出す（「+Y が上」は初期設定のまま）。書き出しの設定の「含める（Include）」で、「カメラ（Cameras）」と「パンクチュアルライト（Punctual Lights）」にチェックを入れる。初期設定ではオフで、オフのままだと `peekScreen` カメラもライトも書き出されない
5. アプリの「ファイル → インポート → ワールド (.glb / .gltf)…」で取り込む

取り込むと、Blender で親を持たないオブジェクト（床、机、ねこ、ライトなど）が、それぞれ1つのオブジェクトとして一覧に並ぶ。位置・角度・大きさは Blender のまま。ファイルは1つだけシーンに入り、部品どうしで共有される。

- Blender で親子にしたオブジェクトは、親と一緒に1つのオブジェクトになる（骨（Armature）の入ったキャラクターは、メッシュを骨の子にしておく）
- `peekScreen` 以外のカメラは使わない

### モデルを入れる

ひとかたまりのモデル（ねこなど）は、「ファイル → インポート → モデル (.glb / .gltf)…」（または一覧の「モデルを追加…」）で足す。スクリーンの正面・床の上に、約30cmの大きさに合わせて置かれる（`peekScreen` カメラが入っていれば、Blender の位置と大きさのまま置かれ、スクリーンが合わせられる）。FBX は事前に Blender などで glb に変換しておく。

### オブジェクトを直す

- オブジェクトは、一覧かシーンビューでの左クリックで選んで、位置・角度・大きさを変えたり、複製・削除したりできる
- ワールドの部品は、「Blender の値に戻す」で Blender での位置・角度（大きさは ×1）に戻せる。大きさは Blender での大きさに掛ける倍率
- スクリーン（ディスプレイ）は、位置・向き、画面サイズ、目と画面の距離を変えられる。`peekScreen` カメラの入ったワールドやモデルがあれば、「〜の peekScreen カメラに合わせる」でその位置に戻せる
- 一覧の「ライト」で、アプリの太陽光の明るさ（ルクス）と向き、環境光の明るさを変えられる。シーンごとに保存される。ライトの入ったオブジェクトがあるときは、アプリの太陽光は消え、そのライトで照らす（環境光は効く）。ワールドのライトは一覧に「ライト」として並び、ほかのオブジェクトと同じように角度を変えられる
- オブジェクトのプロパティの「シーンビューのクリックで選ぶ」を外すと、シーンビューでクリックしても選ばれず、クリックが後ろのものに届く（床や壁を誤って選ばないように。一覧からは選べる）。シーンに保存される
- 新しいシーンに最初から置いてある「部屋」（チェッカー模様の床と壁）も普通のモデル。いらなければ削除できる

### 共有

シーンの `.peek` ファイルを1つ渡せば、ほかのPCでも同じシーンが開ける。「ファイル → エクスポート → シーン (.peek)…」で、今のシーン（保存していない変更も含む）を好きな場所に書き出せる。受け取った側は「ファイル → インポート → シーン (.peek)…」で取り込む（scenes フォルダにコピーされて開く）。

### キー操作

選択中のオブジェクト（またはスクリーン）は、キーでも動かせる（パネルで文字を入力している間は効かない）。すべての操作方法は「ヘルプ → 操作方法」にもある。

| キー | 操作 |
|---|---|
| ↑ / ↓ | Z軸に沿って移動（↑で -Z） |
| ← / → | X軸に沿って移動（→で +X） |
| PageUp / PageDown | 上下に移動 |
| R / F | X軸まわりに回転 |
| Q / E | Y軸まわりに回転 |
| Z / X | Z軸まわりに回転 |
| + / - | 拡大・縮小（ライトを選んでいるときは明るさ） |
| Shift を押しながら | ゆっくり動かす |
| Ctrl+Z / Ctrl+Shift+Z | 元に戻す / やり直し（Ctrl+Y でもやり直し） |
| Ctrl+S / Ctrl+Shift+S | 保存 / 名前を付けて保存 |
| Ctrl+N | 新規シーン |
