## 前提知識 1: Bevy の考え方（これだけ分かれば読める）

このアプリは **Bevy**（ゲームエンジン）の **ECS** という仕組みで書かれています。
普通のプログラムと考え方が違うので、最初にここを押さえてください。

### 登場人物

| 用語 | たとえ | このアプリでの例 |
|---|---|---|
| **Entity（エンティティ）** | 「モノ」の背番号。それ自体は空っぽ | カメラ1台、モデル1体、ライト1つ |
| **Component（コンポーネント）** | モノに貼る「シール」。データを持つ | `Transform`（位置・向き）、`Camera`、`MainCamera`（目印） |
| **Resource（リソース）** | アプリ全体で1つだけのデータ | `AppConfig`（config.ini の中身）、`SceneLayout`（シーン）、`HeadPose`（頭の位置） |
| **System（システム）** | 毎フレーム自動で呼ばれる関数 | `receive_udp`（頭の位置を受け取る）、`update_off_axis_projection` |
| **Plugin（プラグイン）** | システムやリソースをひとまとめにした「機能の箱」 | `TrackingPlugin`、`ScenePlugin` |
| **State（ステート）** | アプリの「今の状態」 | `AppMode`（ホーム／本番／検査／編集） |

### システムの引数の読み方

システム（関数）の引数には「何を使いたいか」を書きます。Bevy が自動で渡してくれます。

```rust
fn receive_udp(
    config: Res<AppConfig>,        // Res<型>     … リソースを読むだけ
    mut pose: ResMut<HeadPose>,    // ResMut<型>  … リソースを書き換える
) { ... }

fn sync_scene_objects(
    mut commands: Commands,                             // Commands … モノを作る・消す・シールを貼る
    mut placeables: Query<(Entity, &Placeable, &mut Transform)>,
                                                        // Query … 「Placeable シールが貼ってあるモノ全部」を探して、その Transform を書き換える
) { ... }
```

| 引数の型 | 意味 |
|---|---|
| `Res<T>` / `ResMut<T>` | リソースを読む / 書く |
| `Option<Res<T>>` | リソースが無いかもしれない（無ければ `None`） |
| `Query<(A, &B, &mut C), With<D>>` | D のシールが貼ってあるモノから、A・B・C を取り出す。`&mut` は書き換え |
| `Single<...>` | Query の結果がちょうど1つのときに使う |
| `Commands` | モノの生成（`spawn`）、削除（`despawn`）、シールの追加（`insert`）・除去（`remove`） |
| `Local<T>` | そのシステム専用の、フレームをまたいで残る変数 |
| `MessageReader<T>` | イベント（マウスの動き、アプリ終了など）を受け取る |

### いつ呼ばれるか（スケジュール）

```rust
app.add_systems(Startup, setup_light)        // 起動時に1回だけ
   .add_systems(PreUpdate, receive_udp)      // 毎フレーム、最初のほう
   .add_systems(Update, sync_scene_objects)  // 毎フレーム、メイン
   .add_systems(PostUpdate, update_outline)  // 毎フレーム、後のほう
   .add_systems(Last, close_opentrack_on_exit) // 毎フレーム、最後
```

条件付きにもできます。

```rust
edit_panel.run_if(in_state(AppMode::Edit))               // 編集モードのときだけ
sync_scene_objects.run_if(resource_changed::<SceneLayout>) // SceneLayout が変わったフレームだけ
(a, b, c).chain()                                         // a → b → c の順番を保証する
```

### Observer（オブザーバー）

「何かが起きたときだけ」呼ばれる関数です。このアプリでは2か所で使っています。

- `select_on_click`（editor.rs）… モノがクリックされたとき
- `on_model_ready`（model.rs）… モデルの読み込みが終わったとき

## 前提知識 2: Rust でよく出てくる書き方

| 書き方 | 意味 |
|---|---|
| `Option<T>` | 値が「ある（`Some(x)`）」か「無い（`None`）」か |
| `Result<T, E>` | 「成功（`Ok(x)`）」か「失敗（`Err(e)`）」か |
| `let Some(x) = 式 else { return; };` | 値が無ければここで抜ける。あれば `x` に入れて続ける |
| `if let Some(x) = 式 { ... }` | 値があるときだけ実行する |
| `match 値 { A => ..., B => ..., _ => ... }` | 値によって分岐する（switch 文のようなもの） |
| `?` | 失敗（`Err` / `None`）ならその場で関数を抜ける |
| `\|x\| x + 1` | 無名関数（クロージャ） |
| `&x` / `&mut x` | 借りて読む / 借りて書き換える |
| `#[derive(...)]` | よくある機能（コピー、比較、表示など）を自動で付ける |
| `#[cfg(windows)]` | Windows のときだけコンパイルする |
| `#[cfg(test)] mod tests` | テスト用のコード（`cargo test` で動く。アプリ本体には入らない） |
| `impl 型 { fn ... }` | その型に関数（メソッド）を付ける |
| `pub` | ほかのファイルからも使える |

## 1フレームの中で起きていること（全体の流れ）

本番モードで、頭を動かしたときに画面が変わるまで:

```
[PreUpdate]
  display.rs   update_display_info  … モニターの画素数と config から画面の実寸を出す → DisplayInfo
  tracking.rs  receive_udp          … OpenTrack から届いた頭の位置を読む       → HeadPose

[Update]
  app_mode.rs  update_camera_layout … モードに合わせて、どのカメラをどこに描くか決める
  scene.rs     sync_scene_objects   … SceneLayout が変わっていたら、モデルを動かす・増やす・消す
  off_axis_projection.rs
               update_off_axis_projection
                                    … HeadPose + DisplayInfo + スクリーンの位置
                                      → メインカメラの位置と視錐台（見える範囲）を決める

[描画]
  Bevy がメインカメラから見た映像を描く
```

編集モードでは、これに加えて次の処理が動きます。

```
  edit_panel.rs  edit_panel     … パネルの操作で SceneLayout / AppConfig を書き換える
  editor.rs      keyboard_edit  … 矢印キーなどで SceneLayout を書き換える
  editor.rs      track_history  … 変更を「元に戻す」の履歴に記録する
       ↓ SceneLayout が変わる
  scene.rs       sync_scene_objects … 3D空間に反映される
```

**データ（SceneLayout）を書き換える → それを見て3D空間が自動で追いかける**、という一方通行の作りになっています。
UI のコードは3Dのモノを直接動かしません。ここを押さえると全体が読みやすくなります。

## 主なリソース（アプリ全体で1つのデータ）早見表

| リソース | 定義 | 中身 | 誰が書く |
|---|---|---|---|
| `AppConfig` | config.rs | config.ini の値 | 起動時に読む、編集パネル |
| `DisplayInfo` | display.rs | 画面の画素数と実寸(m) | display.rs が毎フレーム |
| `HeadPose` | tracking.rs | 頭の位置 x, y, z (cm) | tracking.rs が毎フレーム |
| `SceneLayout` | layout.rs | スクリーンの位置、ライト、オブジェクト一覧 | 編集パネル、キー操作、取り込み |
| `SceneLibrary` | library.rs | 今開いているシーンの名前 | シーンを開く・保存するとき |
| `PackageStore` | package_store.rs | シーンの中のモデルファイルの中身 | シーンを開く・取り込むとき |
| `LoadedModels` | model.rs | 読み込み終わったモデルの情報 | モデルの読み込みが終わったとき |
| `EditState` | editor.rs | 選択中のもの、保存済みの内容、元に戻す履歴、ダイアログ | 編集モード |
| `State<AppMode>` | app_mode.rs | 今のモード | ホーム画面、Esc |
