# 08 camera/scene_view.rs　外から見るカメラと補助線

**一言で**: 3D空間を外から見るカメラ（マウスで回せる）と、座標軸・スクリーンの枠などの補助線（ギズモ）を描く。
**場所**: `src/camera/scene_view.rs`（226行）
**関係するファイル**: [02 app_mode](02_app_mode.md)（オン／オフ）、[18 editor](18_editor.md)（選択）、[19 highlight](19_highlight.md)（選択色）

---

## このファイルの役割

ホーム画面の背景、検査モードの左側、編集モードのメイン画面に出る「シーンビュー」を担当します。

1. カメラを作る
2. マウス操作（右ドラッグで回転、ホイールでズーム、ホイールを押してドラッグで平行移動）
3. 補助線を描く（座標軸、目の位置、スクリーンの枠）

---

## 定数（15〜29行目）

| 定数 | 値 | 意味 |
|---|---|---|
| `GIZMO_LAYER` | 1 | 補助線専用の「レイヤー」番号 |
| `HOME_ROTATE_SPEED` | 0.1 | ホーム画面で背景がゆっくり回る速さ |
| `OUTLINE_LINE_WIDTH` | 8.0 | 選択中のスクリーンの縁取りの太さ |
| `PAN_SPEED` | 0.0015 | 平行移動の速さ |

### レイヤーとは

Bevy では、モノを「レイヤー」に分けて、カメラごとに **どのレイヤーを映すか** を選べます。

| レイヤー | 何がある | 映すカメラ |
|---|---|---|
| 0（標準） | モデル、部屋など | シーンビュー、メインカメラ |
| 1（`GIZMO_LAYER`） | 補助線、選択の輪郭線 | **シーンビューだけ** |

だから、座標軸やオレンジの枠は本番の映像には映りません。

## `SceneViewCamera`（31〜50行目）

```rust
pub struct SceneViewCamera {
    radius: f32,  // 中心からの距離（ズーム）初期値 4m
    alpha: f32,   // 横の回転角
    beta: f32,    // 縦の回転角（真上からの角度）
    focus: Vec3,  // 見ている中心の点（平行移動で動く）
}
```

カメラは `focus` を中心とした球の表面を動きます（**オービットカメラ**）。

## 関数ごとの説明

### `setup_scene_view_camera`（64〜77行目）

カメラを作ります。`RenderLayers::from_layers(&[0, GIZMO_LAYER])` で、通常のモノと補助線の両方を映します。

### `setup_gizmo_layer`（80〜90行目）

補助線の設定です。

- 普通の補助線を `GIZMO_LAYER` に置く
- 選択の縁取り用の補助線（`SelectionOutlineGizmos`）も同じレイヤーに置き、太さ 8px、少し奥（`depth_bias`）に描く
  → 細い線が太いオレンジ線の上に重なり、縁取りに見える

### `draw_grid_and_gizmos`（93〜135行目）　補助線を描く

毎フレーム描き直します（ギズモは描いたフレームだけ表示される仕組み）。

| 描くもの | 色 | コード |
|---|---|---|
| 原点の座標軸（長さ5m） | 赤=X、緑=Y、青=Z | `gizmos.axes(...)` |
| 目の位置（小さな球） | マゼンタ | `gizmos.sphere(cam_pos, 0.03, ...)` |
| 目からスクリーンの中心への線 | マゼンタ | `gizmos.line(...)` |
| スクリーンの枠（今の画面の大きさ × 縮尺） | マゼンタ | `gizmos.rect(...)` |
| 基準の画面の枠（大きさが違うときだけ） | 灰色 | 130〜134行目 |
| 上の3つの縁取り（編集モードでスクリーンを選んでいるとき） | オレンジ | `outline.xxx(...)` |

目の位置はメインカメラの位置そのもの（`main_cam_query`）です。頭を動かすと球が動くので、検査モードでトラッキングを確認できます。

### `control_scene_view_camera`（139〜226行目）　マウス操作

#### 操作を受け付ける条件（156〜161行目）

```rust
let accepts_input = camera.is_active   // カメラがオン
    && hovered                          // マウスがシーンビューの範囲内
    && !ui_input.pointer                // マウスが UI（パネルなど）の上にない
    && *mode.get() != AppMode::Home;    // ホーム画面ではない
```

ホーム画面では操作できない代わりに、自動でゆっくり回ります（163〜165行目）。

#### ドラッグ（169〜207行目）

```
右ボタン or ホイールボタンを押した瞬間
  → 押した位置を覚える、カーソルを隠して固定する
押している間
  ├ 右ボタン     → 回転（alpha, beta を変える）
  └ ホイールボタン → 平行移動（focus を動かす。遠いほど大きく動く）
離したら
  → カーソルを元の位置に戻して表示する
```

- `drag: Local<Option<(Vec2, MouseButton)>>` は「ドラッグ中なら、始めた位置とボタン」を覚える変数です
- 縦の回転は `rem_euclid(TAU)` で 0〜360° に収めるだけで制限していないので、真上を越えて回れます（越えると上下が逆さま）

#### ズーム（210〜217行目）

ホイール1目盛りで 0.3m 近づく／離れる。0.5m〜20m の範囲に制限。

#### カメラの位置を決める（221〜225行目）

```rust
let yaw = π/2 - cam.alpha;
let elevation = π/2 - cam.beta;
let rotation = Quat::from_rotation_y(yaw) * Quat::from_rotation_x(-elevation);
transform.rotation = rotation;
transform.translation = cam.focus + rotation * Vec3::new(0.0, 0.0, cam.radius);
```

角度から向きを作り、「中心から、その向きの後ろ方向に radius 離れた位置」にカメラを置きます。
`looking_at`（ある点を向く）を使わないのは、真上・真下で向きが急に変わるのを避けるためです。
