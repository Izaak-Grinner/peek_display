## 元に戻す・やり直しの仕組み（198〜258行目）

### 「ひとまとまり」にする工夫

矢印キーを押し続けたりドラッグしたりすると、毎フレーム少しずつ値が変わります。
それを1フレームずつ記録すると、Ctrl+Z を何十回も押すことになります。

そこで、**マウスもキーも離したとき（idle）にまとめて1回分として記録** しています。

```
track_history（毎フレーム）
├ settled（最後に確定した状態）が無い → 今の状態を settled にする
├ まだ押している / 取り込み直後の自動調整中 / 変わっていない → 何もしない
└ 離した & 変わっている → commit
     ├ settled を undo に積む
     ├ 今の状態を新しい settled にする
     └ redo を空にする（新しい変更をしたら、やり直しはできなくなる）
```

### `undo`（235〜242行目）

```
1. まだ確定していない変更があれば、先に確定する（commit）
2. undo から1つ取り出す
3. 今の状態を redo に積む
4. 取り出した状態に戻す（apply）
```

`redo` はその逆です。

### `apply`（253〜258行目）

`layout.restore(...)` でシーンを戻します（id はそのまま → [10 layout](10_layout.md) 参照）。config も戻ります。

## システム（毎フレームの処理）

登録（305〜316行目）: 4つのシステムが **編集モードのときだけ** 順番に動きます。クリックの選択はオブザーバーです。

### `select_on_click`（320〜349行目）　クリックで選ぶ

3Dのモノが左クリックされたら呼ばれます。

```
├ 編集モードでない / 左クリックでない / UI の上 → 何もしない
├ クリックされたモノから親をたどって Placeable を探す
│  （モデルは中にたくさんのメッシュがあるので、当たるのは子のメッシュ）
│  └ 見つかった → そのオブジェクトを選ぶ
└ 見つからない（何もないところ）→ 選択を外す
```

### `keyboard_edit`（351〜419行目）　キーで動かす

```
├ 文字を入力中 / ダイアログが出ている / Ctrl を押している → 何もしない
├ 何も選んでいない → 何もしない
└ 押されているキーから、動かす量を計算する
```

`axis(プラスのキー, マイナスのキー)` は、プラスのキーなら +1、マイナスなら -1、両方か無しなら 0 を返します。

| 値 | プラス | マイナス |
|---|---|---|
| forward | ↑ | ↓ |
| right | → | ← |
| up | PageUp | PageDown |
| turn_x | R | F |
| turn_y | Q | E |
| turn_z | Z | X |
| grow | + | - |

> **C キーを使っていない理由**（378行目）: C は OpenTrack のセンター合わせに予約されているため。

```rust
let dt = time.delta_secs() * if slow { SLOW_FACTOR } else { 1.0 };  // 前のフレームからの時間
let delta = Vec3::new(right, up, -forward) * MOVE_SPEED * dt;
```

フレームの時間を掛けるので、パソコンの速さに関係なく「1秒で20cm」動きます。
↑ が -Z なのは、スクリーンから奥が -Z だからです。

選んでいるものごとの動き:
- スクリーン: 移動と回転（大きさは変えない）
- ライト: R/F で傾き、Q/E で方角、+/- で明るさ
- オブジェクト: 移動、回転、大きさ

### `track_history`（423〜434行目）

マウスもキーも押していなくて、文字入力中でもないときを `idle` として、`EditState::track_history` を呼びます。
`bypass_change_detection()` は「EditState を書き換えたけど、変更扱いにしない」という指定です（毎フレーム変更扱いになるのを防ぐ）。

### `update_click_through`（442〜462行目）

「シーンビューのクリックで選ぶ」のチェックを外したオブジェクトのメッシュに `Pickable::IGNORE` を付けて、クリックが後ろのものに届くようにします。
モデルのメッシュは読み込み後に増えるので、毎フレーム確認しています。

### `draw_selection`（465〜494行目）

選んでいるものの目印を描きます（シーンビューだけに映る）。

| 選択 | 目印 |
|---|---|
| オブジェクト | 回転・拡大の中心に小さなオレンジの点（輪郭線は [19 highlight](19_highlight.md)） |
| ライト | スクリーンの少し上から、光の向きにオレンジの矢印 |
| スクリーン | ここでは描かない（[08 scene_view](08_scene_view.md) が縁取る） |
