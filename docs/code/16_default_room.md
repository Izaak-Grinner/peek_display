# 16 scene/default_room.rs　チェッカー模様の部屋を作る

**一言で**: 新しいシーンに最初から置く「部屋」（チェッカー模様の床、壁、天井）のモデルファイル（.gltf + .bin）をプログラムで作る。
**場所**: `src/scene/default_room.rs`（255行）
**関係するファイル**: [15 library](15_library.md)・[23 edit_panel](23_edit_panel.md)（新規シーンで呼ぶ）

---

## なぜプログラムで作るのか

部屋を Bevy の機能で直接描くのではなく、**取り込んだモデルと同じ .gltf ファイル** として作っています。
こうすると部屋も普通のモデルとして扱えて、
- 部品（床、壁、天井）ごとに動かしたり消したりできる
- .peek に一緒に保存される
- ほかのPCに渡しても同じ部屋になる

という利点があります。

## 部屋の大きさ（9〜21行目）

| 定数 | 値 | 意味 |
|---|---|---|
| `TILE_SIZE` | 0.1 | 床のタイル1枚 10cm |
| `HALF_WIDTH_TILES` | 6 | 左右に6枚ずつ → 幅 1.2m |
| `DEPTH_TILES` | 10 | 奥行き10枚 → 1.0m |
| `ROOM_HEIGHT` | 0.8 | 高さ 0.8m |
| `WALL_THICKNESS` | 0.02 | 壁の厚さ 2cm |
| `FLOOR_THICKNESS` | 0.002 | 床の厚さ 2mm |

スクリーン（原点）から見ると:

```
        天井 (y=0.65)
   ┌─────────────────┐
   │      奥の壁      │  ← z = -1.0
左 │                 │ 右
の │                 │ の
壁 │  チェッカーの床  │ 壁    ← 床 y = -0.15 (FLOOR_Y)
   └─────────────────┘
   x=-0.6   スクリーン(z=0)   x=+0.6
```

チェッカー模様は、奥行きの目印になります（頭を動かしたときに奥行きが分かりやすい）。

## 関数ごとの説明

### `room_files()`（29〜84行目）

1. 4つの色（明るい床、暗い床、壁、天井）のマテリアルを作る
2. 床のタイルを、色ごとに1つのメッシュにまとめる（`(ix + iz)` が偶数か奇数かで色を分ける）
3. 5つの部品（床、奥の壁、左の壁、右の壁、天井）を作る
4. `write_gltf` で .gltf と .bin にする
5. `models/room/room.gltf` と `models/room/room.bin` として返す

### `Part`（87〜92行目）・`Geometry`（95〜123行目）

| 型 | 意味 |
|---|---|
| `Part` | 部品1つ（名前、中心の位置、メッシュとマテリアル番号の組） |
| `Geometry` | メッシュ（頂点の位置、法線、三角形の頂点番号） |

`add_box(center, size)` は直方体を足します。6つの面ごとに4つの頂点と2つの三角形を作り、法線（面の向き）を外向きにします。
面ごとに頂点を分けているのは、角で光の当たり方がくっきり分かれるようにするためです。

### `material(name, color)`（127〜133行目）

glTF のマテリアル（JSON の文字列）を作ります。glTF の色はリニア色空間で書く決まりなので `to_linear()` しています。

### `write_gltf(parts, materials)`（136〜221行目）

glTF の形式に沿って、JSON と バイナリを手で組み立てています。

```
.bin（バイナリ）: [頂点の位置][法線][三角形の番号][頂点の位置][法線]...
.gltf（JSON）:
  buffers      … .bin ファイル全体
  bufferViews  … .bin の「何バイト目から何バイト」
  accessors    … それを「小数3つ組 × 何個」などと解釈する方法
  meshes       … 部品ごとの形（どの accessor を使うか）
  nodes        … 部品ごとの名前と位置
  scenes       … どの node を表示するか
```

- `push` クロージャ: データを .bin の最後に足し、bufferView と accessor を作る。4バイト単位にそろえる（glTF の決まり）
- 34962 / 34963 は glTF の決まった番号（頂点データ / 三角形の番号）
- 5126 / 5125 は「32ビット小数」「32ビット整数」

### `new_scene()`（232〜237行目）

空のシーンに「部屋」のモデルを1つ置いて、ファイルと一緒に返します。新規シーンのときに呼ばれます。
